## Prerequisites

Install [APM](https://microsoft.github.io/apm/): the Agent Package Manager:

::code-group

```bash [macOS / Linux]
curl -sSL https://aka.ms/apm-unix | sh
```

```powershell [Windows]
irm https://aka.ms/apm-windows | iex
```

::

Verify the installation:

```bash
apm --version
```

## Install Gem Team

```bash
# Project-scoped (recommended for teams)
apm install mubaidr/gem-team --target copilot,claude,cursor,opencode,codex,gemini,windsurf

# Global user-scoped
apm install -g mubaidr/gem-team

# Pin a specific release
apm install 'mubaidr/gem-team#gem-team-v<version>' --target copilot
```

Replace `<version>` with a tag from [GitHub Releases](https://github.com/mubaidr/gem-team/releases).
APM records the resolved commit in `apm.lock.yaml`, so later installs stay reproducible.

## Update an Existing Installation

```bash
# Project-scoped
apm update mubaidr/gem-team --yes

# Global user-scoped
apm update -g mubaidr/gem-team --yes
```

Use `apm self-update --check` to check for an APM CLI update without installing it.

## Verify

```bash
apm list
apm view mubaidr/gem-team
apm audit
```

Tool-specific checks:

```bash
copilot plugin list      # GitHub Copilot CLI
/plugin list             # Claude Code (inside Claude Code)
```

## APM Flags

| Flag                     | Purpose                                    |
| ------------------------ | ------------------------------------------ |
| `--dry-run`              | Preview changes without writing files      |
| `--target claude,cursor` | Install only selected targets              |
| `--target all`           | Install all supported targets              |
| `--exclude codex`        | Exclude a target from auto-detection       |
| _(no flags)_             | Reinstall from existing `apm.yml` manifest |

Use `--refresh` for a stale upstream cache. For normal upgrades, use `apm update [PACKAGE] --yes`.

## What Gets Installed

APM writes different files depending on the selected target:

| Target     | Output                                                                             |
| ---------- | ---------------------------------------------------------------------------------- |
| `copilot`  | `.github/agents/`, `.github/instructions/`, `.github/prompts/`, VS Code MCP config |
| `claude`   | `.claude/agents/`, `.claude/rules/`, commands, skills, hooks, MCP config           |
| `cursor`   | `.cursor/agents/`, `.cursor/rules/`, skills, commands, hooks, MCP config           |
| `opencode` | `.opencode/agents/`, commands, skills, MCP, compiled instructions                  |
| `codex`    | `.codex/agents/`, `AGENTS.md`, Codex config                                        |
| `gemini`   | `GEMINI.md`, skills/instructions, Gemini config                                    |
| `windsurf` | `.windsurf/rules/`, skills, commands, hooks, MCP config                            |

Commit generated project files, especially `apm.yml`, `apm.lock.yaml`, and harness directories. Keep `apm_modules/` in `.gitignore`.

Direct Git installs read source primitives from `.apm/`; the generated `build/` directory is not required.
