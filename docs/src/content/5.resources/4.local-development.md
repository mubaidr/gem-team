## From Source

```bash
git clone https://github.com/mubaidr/gem-team.git
cd gem-team

# Dry-run first to preview
apm install . --target claude,cursor --dry-run

# Real install from local path
apm install /absolute/path/to/gem-team --target claude,cursor
```

## Package Validation

```bash
apm audit
apm compile --target copilot,claude,cursor --validate
apm pack
```

## Agent and Skill Sources

- Agent definitions: `.apm/agents/*.agent.md`
- Packaged skills: `.apm/skills/*/SKILL.md`
- The standalone `gem-critic` agent was removed. Plan challenge behavior is now
  part of `gem-reviewer`, which supports `plan`, `wave`, and `full` modes.
- `gem-reviewer` also provides additive `critic` mode for `discuss`,
  `proposal`, `feature_idea`, and `challenge` intents. Critic mode is
  read-only: it does not implement proposals or mutate files. Its structured
  output reports a verdict, challenges, alternatives, and decision blockers;
  each reported record includes evidence, impact, and action.

  When testing critic mode locally, provide `critic_subject` and
  `critic_context` with all required fields. The source contract is in
  `.apm/agents/gem-reviewer.agent.md`; the orchestrator forwards these objects
  without renaming them.

When adding or changing a skill, keep its `name` aligned with the directory name and its description specific
enough to support task matching. Rebuild or repack the package before validating generated tool targets.

## Docs Site

The docs site lives at `docs/src/`: a Nuxt 4 app with Nuxt UI & Nuxt Content.

```bash
cd docs/src
npm install
npm run dev
```

> See [Nuxt Content docs](https://content.nuxt.com) for MDC syntax and authoring.
