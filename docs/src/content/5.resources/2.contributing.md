Contributions are welcome. Read [CONTRIBUTING.md](https://github.com/mubaidr/gem-team/blob/main/CONTRIBUTING.md) before opening a PR.

## Recommended Flow

1. **Pick or open an issue** in the [issue tracker](https://github.com/mubaidr/gem-team/issues).
2. **Create a focused branch** with one feature or fix per PR.
3. **Add or update tests and docs** where relevant.
4. **Run validation** before opening the PR.

For package changes, run:

```bash
apm run check
```

For documentation changes, run the site checks:

```bash
cd docs/src
npm run lint
npm run typecheck
npm run build
```
