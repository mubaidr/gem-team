## APM Targets

| Target     | Tool / harness                       | Typical output                                                              |
| :--------- | :----------------------------------- | :-------------------------------------------------------------------------- |
| `copilot`  | VS Code Copilot / GitHub Copilot CLI | `.github/agents/`, `.github/instructions/`, `.github/prompts/`, VS Code MCP |
| `claude`   | Claude Code                          | `.claude/agents/`, `.claude/rules/`, commands, skills, hooks, MCP           |
| `cursor`   | Cursor                               | `.cursor/agents/`, `.cursor/rules/`, skills, commands, hooks, MCP           |
| `opencode` | OpenCode                             | `.opencode/agents/`, commands, skills, MCP, compiled instructions           |
| `codex`    | Codex CLI                            | `.codex/agents/`, `AGENTS.md`, Codex config                                 |
| `gemini`   | Gemini CLI                           | `GEMINI.md`, skills/instructions, config                                    |
| `windsurf` | Windsurf / Cascade                   | `.windsurf/rules/`, skills, commands, hooks, MCP                            |

> APM compiles or skips unsupported primitives for each target.

## Marketplace Installation

APM is recommended; direct marketplace installs are optional.

### GitHub Copilot CLI

```bash
copilot plugin marketplace add mubaidr/gem-team
copilot plugin marketplace browse gem-team
copilot plugin install gem-team@gem-team
```

### Claude Code

```bash
/plugin marketplace add mubaidr/gem-team
/plugin
/plugin install gem-team@gem-team
/reload-plugins
```

### awesome-copilot

For VS Code users, [awesome-copilot](https://github.com/mubaidr/awesome-copilot) offers manual plugin installation through VS Code extensions.

## Tool-Specific Troubleshooting

| Tool        | Common Issue         | Fix                                                      |
| ----------- | -------------------- | -------------------------------------------------------- |
| Copilot     | Agents not showing   | Reload VS Code window (`Ctrl+Shift+P` → "Reload Window") |
| Claude Code | Commands not found   | `/reload-plugins`                                        |
| Cursor      | Rules not applying   | Restart Cursor                                           |
| OpenCode    | Skills missing       | `opencode plugin update mubaidr/gem-team`                |
| Codex       | AGENTS.md not loaded | Restart Codex session                                    |
| Gemini      | Config not applied   | Check `GEMINI.md` in project root                        |
| Windsurf    | Rules not active     | Restart Windsurf                                         |

## Multi-Tool Workflow Example

**Use different tools for different phases — all share the same plan:**

```bash
# Plan with Copilot (strong reasoning)
copilot chat --agent gem-orchestrator "Plan the user search feature"

# Implement with Cursor (fast editing)
# Cursor automatically sees the same plan.yaml

# Review with Claude Code (strong analysis)
claude
> /gem-reviewer Review plan 20250115-user-search-api

# All tools share: docs/plan/20250115-user-search-api/
```

**Plan artifacts are the source of truth** — not tool-specific state.
