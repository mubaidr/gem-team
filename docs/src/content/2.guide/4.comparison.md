## Gem Team vs. Other Tools

Gem Team is not a replacement for Copilot, Cursor, Claude Code, or Cline. It adds an engineering process around them.

### What Gem Team Adds

> Gem Team is the engineering lead: it breaks down work, assigns specialists, checks quality, and learns. Your existing AI tool remains the engine.

| You get                          | Gem Team                                                                 | Typical AI chat                        |
| :------------------------------- | :----------------------------------------------------------------------- | :------------------------------------- |
| **Reliable multi-step delivery** | Coordinated specialist agents                                            | One chat prompt                        |
| **Structured planning**          | Ordered waves, handoffs, and risk checks                                 | Ad-hoc prompts                         |
| **Scoped context**               | Task handoffs, bounded planning_context, and evidence-by-reference       | Full, bloat-prone history              |
| **Quality gates**                | Plan validation, integration checks, security, and a11y audits           | Manual review                          |
| **Root-cause debugging**         | Debugger → Implementer → deterministic or risk review                    | Direct fix attempts                    |
| **TDD by default**               | Red-Green-Refactor with six test dimensions                              | Optional                               |
| **Parallel execution**           | Parallel tasks within waves; serialized wave barriers                    | Sequential                             |
| **Resumable progress**           | Exact plan IDs and `plan.yaml` for MEDIUM/HIGH work                      | Stateless                              |
| **Lower token costs**            | Model routing, output hygiene, scoped handoffs, and high cache-hit rates | Fixed model cost, full history re-sent |
| **Learning over time**           | Skill extraction, confidence-gated memory, and stable cache              | No persistence                         |

### When to Use Gem Team

**Use Gem Team when you want AI coding to follow an engineering process** instead of a single prompt. It is ideal for:

- Multi-file features that need coordination
- Bug fixes that need root-cause analysis
- Reviews with security and accessibility checks
- Projects with shared conventions and reusable knowledge
- Reproducible, auditable AI-assisted workflows

**Use direct chat** for quick questions, simple snippets, or exploratory coding where structured process would add overhead.
